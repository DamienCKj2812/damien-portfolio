# Project-hallway guidance

- Master `project-hallway.blend`. `docs/project-catalogue.md` owns the 16 reviewed projects, descriptions, roles, evidence and links. `build_project_catalogue.py` generates `projects.json`, preserving full catalogue sections and fitted card text; full hallway builds invoke it automatically. The original public snapshot is retained separately. `hallway-layout.json` is generated placement/category/bookmark metadata. FYP leads Academic as one featured exhibit with three repositories; DSTR groups both parts; empty TXSA Part 2 is omitted; RTS is included.
- `hallway_layout.py` owns the spacious layout: 14.2 m hall width, 14.4 m floor, board centres X=±4.8 m, 11.5 m same-side spacing, 3 m right-side stagger and 126.2 m length. The main builder's `-- --layout-only --no-render` mode refreshes the existing scene without importing/rerolling NPCs; original morph geometry/actions and loop timing are retained while rig positions/targets are relocated. Keep the entrance/main camera fixed and publish width through room destinations/journey metadata. Run `node --import tsx scripts/verify_spacious_hallway.mts` after export.
- The public project name is DWMLight / ANVA CMS. Its stable project/repository ID remains `Aria`, and frontend URLs retain `maxscale-io/Aria`. For a title-only authoring update, regenerate the catalogue and run `refresh_project_content.py -- --id Aria` against the master, then re-export Projects; it preserves the completed hallway and all NPC actions.
- Website URLs and access labels are explicit catalogue fields: MyRumawip and DWMLight use Website links, AMPLYFII uses Preview (unreleased), and MyReport is private via Tailscale with no public site URL. Private/organization repository references stay internal and are stripped by the public room exporter; use `node --import tsx scripts/verify_public_links.mts` after export.
- The builder reads `../cyber-city/monochrome-city-solid-tower.blend` to copy local NPC points, without saving/linking the city. Keep that dependency available when rebuilding.
- Full build: `blender --background --python-exit-code 1 --python assets/project-hallway/build_project_hallway.py -- --no-render`. It resets factory data and writes the master; it sets `save_version=0`, so preserve manual edits/recovery before running it.
- For ceiling-only updates, use `-- --ceiling-only --no-render`; the builder verifies the non-ceiling fingerprint. `-- --preview-only --all-previews` renders existing data without a full rebuild.
- Movement stays on X=0 and +Y/-Y, independent of yaw, at Z=2.45. The free-look camera is unanimated; the optional walkthrough camera is not the website entry camera.
- Agent Property/MyRumawip, MyReport and DWMLight are 4.6 × 2.5875 m 16:9 video boards with no printed descriptions. `widen_video_board.py -- --id <project-id>` updates only the selected assembly and fits its frame/projector rays in board-local space, preserving all surrounding objects/actions and the 20° orientation. Stable IDs are `agent-property`, `report-automation` and `Aria`. The generator reads `project.video` dimensions; the runtime uses demand-rendered video textures with outside-board hover/centred prompts. Clicking enters normal project focus and switches that same board to its lazy full video; other previews pause. Check `node --import tsx scripts/verify_project_video.mts` and `node --import tsx scripts/verify_project_video_browser.mts` after export/build; the browser check needs Python/Pillow and video assets as described in [development](../../docs/development.md).
- Preserve all 15 NPC transform/morph performances and the 1200-frame global cycle. Native morph deltas/weights export once at stride 16; standing still must not stop the independent visitor clock.
- Project cards face inward with a fixed 45° yaw toward the entrance, mirrored on the left/right. `board_orientation.py` owns this angle; the layout refresh applies it to complete assemblies. Export authored face normals/right axes, actual local face dimensions and front depth so videos and focus cameras follow the tilt. Pure-dot pillars have no solid cores. The ceiling has 41 sculpted S-wave ribs, five curved integrated light strips and two perimeter rails; preserve the dark multi-face materials and minimum 5.878 m light clearance. No ceiling grid/dots/recessed circular lamps.
- Keep floor projector assemblies aligned to their original walkway lanes through `stabilize_projector`; only retarget beam endpoints to angled boards. Rotating the floor equipment with the screen reduces walker clearance. Run the full native hallway validator after orientation changes.
- Client starts open, with no door. Academic and Personal use native `categoryFrame`, `categoryCurtain` and `categoryDoorLabel` groups: satin framing, white rails, transparent/smoked veils, fine filaments and dust. The passage is always open; lights/lettering reveal after preceding displays and veils clear near the camera. No clicks, sliding leaves, pending entry or portal collision limits. Walking/scroll/seek remain continuous. Category visits and the top-right label derive from actual camera position. Details stay in the sidebar; the archived meeting-room source is not loaded/exported for the website. Check `node --import tsx scripts/verify_project_categories.mts` after exporting.
- Export: `blender --background assets/project-hallway/project-hallway.blend --python-exit-code 1 --python assets/journey/export_browser_room.py -- --level projects`. Ceiling changes also require `node --import tsx assets/project-hallway/verify_browser_ceiling.mts`; full checks are in [WORKFLOW.md](WORKFLOW.md).
- The exporter derives `project.card` center/normal/width/height from the actual card mesh. Native card clicks and sidebar selections directly open a responsive three-column case file with fading translucent description/navigation panels, preserving hallway navigation; mobile uses a section selector and reading dock. Escape/Back returns directly to the hallway. Only the entrance Projects directory remains; the Selected Work exhibition-guide board and its projector are retired. Hidden visitors suspend during focus and resume without a hidden-time jump. Check `node --import tsx scripts/verify_project_card_focus.mts` for every card, facing, viewport and case-file layout.
- `directory_board.py` raises the first board to Z=2.0…5.15, aims the board/top projector at the entrance, and shows Category 01 client/real-world content from the catalogue. Its native `directory` pick opens zoom-only `view="directory"`, with no sidebars and saved hallway return. Use `refresh_directory_board.py` for a preserved-scene update. The top unit is inverted at Z=5.86; regenerated lens/frustum geometry targets the raised card.
- Portal lettering is `02 Academic Assignment Projects` / `03 Personal Projects` via `category_titles.py`. `category_wall_numbers.py` adds thin luminous 02/03 outline curves and light accents to each left partition. Targeted refresh scripts preserve all existing transforms/actions; the full builder also invokes these modules. Check `node --import tsx scripts/verify_project_directory.mts` after build.
