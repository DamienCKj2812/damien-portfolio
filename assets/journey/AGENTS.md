# Integration/export guidance

- Inputs are authored masters in sibling directories. `city-lobby-walkthrough.blend` and `portfolio-journey.blend` are derived copies; never save an integration result over an input.
- Rebuild/export in [WORKFLOW.md](WORKFLOW.md) order. `build_elevator_handoff.py` reads the already exported cabin buffers; city export needs the generated city/lobby copy to include clearance/portal changes.
- `room-destinations.json` is authoritative for source paths, entrance anchors, camera names, animation/guided frames, and four active floor IDs. `build_elevator_handoff.py` publishes it into `public/models/journey.json`; elevator availability reads the same file.
- City end is global 383; the 60-frame camera bridge does not delay city geometry hiding. Lobby end is 1403; cabin selection is global 1521 / local 180. Room load holds departure at local 296; room camera handoff is 414–510.
- Lobby offset is `(-1.5,6.45,0)`; cabin offset includes the 0.20 m recess behind R1. Use `geometry_clearance.py`/door-fitting helpers rather than moving only floors/backings or scaling animated leaves independently.
- Exporters are read-only. Portal masks, removed placeholders, stipple conversion, room front surrounds and pick targets are memory-only. `update_floor_panel.py` in the elevator directory is the explicit master-saving exception.
- Preserve render-role/ID metadata, `buttonDetail` parent assemblies, visibility, closest animated part/root world transforms, morph deltas and route descriptors. Skills stride is 12; About/Projects/Experience stride is 16; do not hand-edit generated offsets/hashes.
- Public room content passes through `public_content.py` using `src/data/repository-visibility.json`: strip private/organization/unknown repository URLs, including Markdown file links and navigation station copies; preserve website URLs and label unreleased previews. Keep the frontend `publicLinks.ts` checks aligned as defense for stale packages. Only verified public, non-organization repositories are linkable; source catalogues may retain private references for internal evidence.
- Restricted repository source rows must be removed completely, including their internal filenames and descriptions. `repositoryLinksRestricted` cards use website-only Sources built from `liveUrl`/`siteLinks`; omit empty Sources sections when no site exists. Keep `publicCaseSections` aligned with the exporter so sanitized packages and stale cached data render consistently.
- Recheck the registry against GitHub public repository listings when repository visibility changes; unknown entries fail closed. Run `node --import tsx scripts/verify_public_links.mts` to audit every published room string and website/access labels.
- Package checks: `node --import tsx assets/journey/verify_rooms.mts` (also included in `npm run verify`). `verify_room_source.py -- --level projects|skills|experience` compares authored transforms/points/morphs/routes; it has no About level option.
- Native handoff checks run against their generated copies: `verify_handoff.py` then `verify_elevator_handoff.py`. Blender flags require `--python-exit-code 1`; scripts use hardcoded `ROOT` in some entry stages.
- The current cylindrical city tower retains the complete orbital sky (without annotation labels), 18 outdoor NPCs and detailed UV-textured Earth hologram. Preserve their render visibility, motion metadata and six reference textures when rebuilding integration; see `../cyber-city/AGENTS.md` for ownership and focused checks.
- City entrance fitting is memory-only: cut the front portal separately from the rear atrium, retain the fixed entrance anchor, and recess door/pocket assemblies by 1.8 m without retiming their actions. Closed leaves must overlap the seam, header and threshold. Enclose the recessed jamb/header/floor depth; use fitted fixed pocket casings with side/back/top/bottom returns to conceal open leaves without broad black planes across the curved storefront.
- `verify_handoff.py` includes 120 closed-sealing and 72 open-leaf-occlusion rays. After a build, `node --import tsx assets/journey/verify_city_entrance.mts` adds browser closed/open/enter/reverse, restored sky/NPC metadata and elevator-arrival checks. Playwright 1.61.1 is a declared dev dependency; `PLAYWRIGHT_MODULE` remains an external-module override, `CHROME_EXECUTABLE` overrides `/usr/bin/google-chrome`, and `VERIFY_OUTPUT_DIR` overrides temporary screenshot output. `FIXED_APPROACH=1` alters only the test camera, not authored/exported animation.
