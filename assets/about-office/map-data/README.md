# Malaysia screen geography

`malaysia-context.geojson` is generated by `malaysia_screen.py` from Natural Earth's public-domain 1:50m country geometry. It retains Malaysia, Thailand, Indonesia, Brunei and Singapore for the screen's regional context. The source URL and source/download hash are recorded in `malaysia-screen.json` beside the office master.

The map is authored as native planar meshes, thin curves and text, not an external screenshot or realized particle geometry. Source country outlines are clipped to the map viewport; both Malaysian regions share the same geographic scale.
