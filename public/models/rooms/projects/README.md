# Projects hallway browser package

Generated read-only from `assets/project-hallway/project-hallway.blend` by
`assets/journey/export_browser_room.py -- --level projects` in background Blender.
NPC point-cloud shape targets and native motion remain separate from the camera.
Keep `scene.json`, `geometry.bin`, and `animation.bin` together.

The ceiling uses broad black coffer panels, thin inset borders, three longitudinal
light strips and dark square junction blocks. It has no surface grid or ceiling
dot layer. The existing native room renderer draws these directly from this package.
