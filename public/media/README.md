# Browser shared media

Audio under `audio/music/` and `audio/effects/` is generated byte-for-byte from
`assets/media/` using `node --import tsx scripts/sync_media_assets.mts`. Do not edit browser
copies directly. See `assets/media/manifest.json` for ownership, original hashes,
destinations and soundtrack attribution. Model packages and their generated
textures remain under `public/models/` and use their own manifests/exporters.
